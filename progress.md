# Roblox AI Copilot - Progress Log

## Status: In Development
- **Target**: Professional Roblox Studio Plugin (`.rbxm`) & Open-source Repo
- **Stack**: Luau (typed `--!strict`), Rojo 7.7.1, HttpService integration
- **Features Planned**:
  1. `AIClient`: Multi-provider HTTP client (Gemini, Groq, DeepSeek, Ollama)
  2. `PromptTemplates`: Expert Luau coding and scene building prompts
  3. `ScriptGenerator`: Natural language to safe, typed Luau scripts with 1-click Insert (Ctrl+Z support)
  4. `SceneBuilder`: Natural language to 3D procedural Roblox scene/props in Workspace
  5. `SecurityAuditor`: Static security scan for RemoteEvent exploit vulnerabilities and DataStore bugs
  6. `UI`: Responsive, theme-aware Studio Dockable Widget with tabs and syntax preview
  7. `Distribution`: One-click `.rbxm` build script and installation guide for Roblox Creator Store & GitHub
